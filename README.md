## Assignment Overview

This repository contains the four parts of the OOP Design Assignment:

### Part 1 — Procedural to OOP
Refactored the procedural order system into an object-oriented C# design using:
- Customer
- Product
- Order
- OrderLine

### Part 2 — Hotel Reservation System
Designed a hotel reservation system with:
- Guest
- Room
- Reservation
- HotelReservationSystem

The implementation includes encapsulation, validation, reservation status transitions, room maintenance, pricing, and double-booking prevention.

### Part 3 — Builder Pattern
Implemented the Builder Pattern for constructing a complex Invoice object.

The solution includes:
- Invoice
- InvoiceBuilder
- AddressBuilder
- OrderBuilder

### Part 4 — LeetCode
Solved:

**1679. Max Number of K-Sum Pairs**

The solution uses sorting and the Two Pointers technique.

## Notes / Assumptions

- Each part is implemented in its own folder and project.
- `bin/` and `obj/` folders are excluded from the repository.
- The solution focuses on clear object-oriented design and separation of responsibilities.
